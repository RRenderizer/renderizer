# Roadmap

## Alpha 1

- Publish `@renderizer/core`.
- Publish `@renderizer/vue`.
- Publish `@renderizer/create`.
- Ship Electron helpers as `@renderizer/vue/electron` and `@renderizer/vue/preload`.
- Provide a minimal Electron + Vue example.
- Document security model and limitations.

## Alpha 2

- Add configurable overlay target support for components that normally teleport to `body`.
- Add window lifecycle events with typed payloads.
- Add optional built-in titlebar controls.
- Add persistence for size, position, maximized and full-screen state.

## Alpha 3

- Add `@renderizer/react` using portals.
- Ship React Electron helpers as package subpaths instead of a separate Electron package.
- Add pure JavaScript examples.
- Add integration recipes for Vite, Vue Router, Pinia, Zustand and TanStack Query.

## Beta

- Validate on Windows, macOS and Linux.
- Add Playwright/Electron smoke tests.
- Stabilize public API names.
- Publish docs site and launch article.
